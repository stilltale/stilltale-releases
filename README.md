# Stilltale Releases

Official release binaries for **[Stilltale](https://stilltale.com/)** — the app
for creating and publishing stories told in stills.

**Download the latest version: https://stilltale.com/download/**

| Platform | Asset |
|---|---|
| macOS (Apple silicon / Intel, universal) | `Stilltale-mac.dmg` |
| Windows (installer) | `Stilltale-win-setup.exe` |

Stilltale collects no telemetry, and your manuscripts never leave your machine.
See the [privacy policy](https://stilltale.com/en/privacy/).
